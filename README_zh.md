# Claude Certified Architect - Foundations (CCAR-F) 备考全景看板 & 学习系统

[English](README.md) | [中文版]

一款专为 **Anthropic Claude Certified Architect - Foundations (`CCAR-F`)** 认证考试打造的高效、隐私优先、零后端的全景备考看板与打卡系统。

本看板严格依据 Anthropic 官方 **Exam Guide v1.0** 权威考纲设计，集成了加权掌握度追踪、双轨每日冲刺计划（7天冲刺 / 14天稳妥）、30 项考点深度库及反模式解析、10 步统一做题决策罗盘、全真 Mock 战绩与 9 大错因笔记本、专注番茄钟以及 AI 刷题教练 Prompt 生成器。

---

## 隐私安全与本地数据架构

- **100% 纯前端零后端**：完全在本地浏览器中运行，无需注册登录，无 Cookie 追踪，无任何第三方分析代码。
- **本地存储（localStorage）**：所有的打卡历史、专注学习时长、自定义考试日期、模拟考试成绩以及错题心得，均保存在本地浏览器的 `localStorage`（键名：`cca-study-companion-v2`）中。
- **代码上传 GitHub 零隐私泄露**：上传至 GitHub 或部署到 GitHub Pages 时，仅包含纯静态的前端页面与静态考纲数据，你个人的打卡进度、心得笔记以及本地文件均不会被同步或公开。
- **便捷备份与恢复**：内置一键 **导出 JSON 备份** 与 **导入 JSON 恢复** 功能，方便在多设备间迁移数据，且无需依赖任何云端服务。

## 核心功能

### 1. 加权掌握度环（Weighted Mastery）
- 严格按照官方 5 大 Domain 权重实时加权计算总体自评掌握度：
  - **Domain 1**: 核心架构与 Agentic 循环 (27%)
  - **Domain 2**: 提示词工程与结构化输出 (18%)
  - **Domain 3**: 工具调用与函数能力 (20%)
  - **Domain 4**: 上下文与知识增强 / RAG (20%)
  - **Domain 5**: 评测验证、安全合规与生产就绪 (15%)

### 2. 双轨每日打卡与学习流水
- 支持 **7 天冲刺**（高强度每日 90-120 分钟）与 **14 天稳妥**（结构化每日 45-60 分钟）学习路线无缝切换。
- 每张任务卡包含建议时长、核心学习目标、实操动作与必做交付产物（Deliverable）。
- 打卡日历热力点阵、连续打卡天数（Streak）激励统计与每日心得复盘存档。

### 3. 专注番茄钟（Pomodoro Focus）
- 内置 **25 分钟**（经典专注）、**50 分钟**（深度推演）、**15 分钟**（考点速记）倒计时。
- 使用浏览器原生 Web Audio API 合成提示音，零音频文件依赖。
- 专注倒计时结束后自动记录累计专注时长，并联动打卡流。

### 4. 30 项考点深度库（30 Task Statements）
- 5 大 Domain 树状展开，卡片包含：
  - **核心原理与最佳做法**：架构考量与官方推荐设计路径。
  - **高频反模式与易错陷阱（Anti-Patterns）**：直击考试中最具迷惑性的错误选项。
  - **掌握证据要求**：检验是否真正掌握的具体代码或工程标准。
- 实时关键字过滤（如 `hooks`, `stop_reason`, `batch`, `mcp`, `sampling` 等）。
- 四阶掌握度跟踪：`0. 未开始`、`1. 理解概念`、`2. 完成练习`、`3. 新题验证`。

### 5. 10 步统一做题决策罗盘与场景矩阵
- **10 步黄金做题判定树**：确定性逻辑优先判定、标准不清 vs 执行不稳、工具选错排查、0 结果与超时隔离等。
- **10 大高频干扰陷阱对比清单**：Prefill 与 Prompt 差异、Batch API 与流式响应、Subagent 与单一工作流等核心辨析。
- **官方 6 大考试场景架构**：客服智能体、代码生成、深度研究分析、长文档处理、多模态质检、结构化数据抽取。
- **一键复制 AI 刷题教练 Prompt**：专为 Claude / ChatGPT 调优的考官系统提示词，随时开启一对一场景化实操摸底。

### 6. Mock 模拟战绩与 9 大错因笔记本
- 记录 60 题 / 120 分钟全真模拟得分、耗时与各 Domain 分项得分。
- 动态判定建议就绪度（两次 Mock 达到 80% 且单项无低于 75%）。
- 错题按 **9 大标准错因分类** 统计与复盘：
  - `criteria`: 题干诉求与验收标准未读透
  - `determinism`: 确定性代码任务误用大模型
  - `tool-routing`: 工具定义、参数 Schema 或路由策略缺陷
  - `overengineering`: 架构过度设计，引入了不必要的复杂代理
  - `error-recovery`: 缺少重试、退避或优雅降级保护
  - `context`: 上下文预算溢出或上下文窗口管理失效
  - `scope`: 选择了超范围或非最佳的设计方案
  - `sla`: 违反延迟、流式响应或成本预算约束
  - `question-limit`: 误解题目反向否定限制或边界条件

### 7. 考前最后一页与资源矩阵
- 10 项考前确认清单（交互勾选持久化保存）。
- 版本演进避坑指南（官方 Exam Guide 与最新 SDK 演进差异比对）。
- 明确不考范围（Out of Scope 过滤，杜绝考前无效内耗）。
- 官方文档与精选社区学习资源直达。

## 启动与运行方式

### 方式 1：直接双击打开（最快捷、零环境依赖）

在文件管理器中找到 `index.html` 双击，或在终端中运行：
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

### 方式 2：使用本地轻量 HTTP 服务

```bash
# 使用 Python 3
python3 -m http.server 8080

# 或使用 Node.js
npx serve .
```
启动后在浏览器中访问：`http://localhost:8080`。

### 方式 3：部署到 GitHub Pages（免费在线个人专属主页）

1. 将本文件夹上传到你的 GitHub 仓库。
2. 进入 GitHub 仓库页面，点击 **Settings** -> **Pages**。
3. 在 **Branch** 下选择 `main`（或 `master`），目录选择 `/`（root），点击 **Save**。
4. 稍等一分钟，即可通过专属链接随时随地在线访问：
   `https://<你的GitHub用户名>.github.io/<仓库名>/`
